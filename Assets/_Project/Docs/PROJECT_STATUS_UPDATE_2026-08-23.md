# 프로젝트 상황 업데이트
Updated: 2026-08-23

## 이번 슬라이스에서 반영한 것
- Echo Overcharge를 remote에 처음 착륙시켰다. Q 탭은 기존 메아리, 홀드는 충전, 릴리즈는 현재 충전으로 시전, 풀충전은 자동 시전한다.
- 과충전은 정찰/안개 범위와 소음만 키운다. 기절 반경과 지속시간은 그대로다.
- HUD는 홀드 중 `Q 과충전 N%`를 보여 주고, 차지 링은 에코 블루에서 경고 레드로 바뀐다.
- 적 스폰 경로(일반 재생성 + set-piece 증원)에 몸통 반경 충돌 여유를 적용했다.
- 체크포인트 좌표를 검증하고, 맵 밖/벽 안/비정상 좌표면 안전한 생성 칸으로 되돌린다. 세이브 로드도 같은 경로를 쓴다.
- 게임이 일시정지되면(`timeScale <= 0`) 리듬 페이즈 시계가 멈추고, 페이즈 진행도 멈춘다.
- 과충전 텔레메트리와 `Echo.OverchargeContract` 회귀 한 줄을 추가했다.

## 아직 열린 것
- Unity 6000.3.8f1 에디터 컴파일 확인
- Play Mode에서 과충전 탭/홀드 느낌 확인. 리듬 스냅샷은 여전히 `NO_EVIDENCE`로 가정하고 차지 초를 조율하지 말 것
- 스모크 안 메아리: 정찰 거리를 줄이고 소음을 낮추는 상호작용 하나. 안정화 1-4가 끝난 뒤에만 진행
- 리듬 페이즈 숫자, 압박, 보상값은 이번에도 손대지 않았다

## 다음 에이전트
1. Unity 콘솔에서 컴파일만 확인한다.
2. Play Mode에서 Q 탭/홀드/풀충전 자동 시전을 한 번씩만 본다. 스냅샷이 없으면 숫자를 바꾸지 않는다.
3. 그다음 작업은 스모크-메아리 상호작용 하나, 또는 스폰/체크포인트 회귀를 Play Mode에서 확인하는 것이다.

## 한 줄 판정
플레이어는 이제 메아리를 더 넓게 들을수록 더 크게 들키는 선택을 할 수 있고, 벽 안 적 스폰이나 잘못된 체크포인트, 일시정지 중 리듬 진행은 피할 수 있다.
