# Core Loop Fun Opportunities
Updated: 2026-05-10

## Core Loop Rhythm Target
`Calm`: read the map, choose a route, notice distant danger.  
`Build`: get tempted by speed, risk cache, corrupted hints, and breadcrumb momentum.  
`Spike`: survive the result of the choice, not a random punishment.  
`Release`: feel relief, recover a little, and prepare the next choice.

## Highest Impact Ideas
1. Release as the reward.
   - Release should not only reduce pressure. It should visibly reward survival through clearer objective whisper, short stamina relief, softened dread audio, or safer route visibility.

2. Build as temptation.
   - Build should surface the best greed decisions: risk cache, exit cache, corrupted breadcrumb, chain momentum.
   - Reward gets more attractive as Spike nears, but the mistake cost also rises.

3. Spike as a short exam.
   - Keep Spike short and legible.
   - Trigger consequences of previous choices: loud exit unlock, risky cache aftershock, chase pressure, or a bad corrupted-hint route.

4. Breadcrumbs as the rhythm spine.
   - Calm pickup: safe, low bonus.
   - Build pickup: stronger momentum, more noise.
   - Spike pickup: clutch reward, maybe early Release or temporary pressure relief.
   - Release pickup: next Calm starts with clearer guidance.

5. Risk cache as the "one more" button.
   - Risk cache should be most visible during Build.
   - If ignored, it can fade or weaken in Release.
   - If taken, it can boost reward while making the next Spike sharper.

6. Exit unlock as drama, not bookkeeping.
   - Last breadcrumb -> brief Build crest -> exit unlock noise -> Spike -> Release whisper toward exit.
   - This makes objective completion start the final escape scene instead of ending tension.

7. Corrupted breadcrumb fairness.
   - Corruption should build confusion during Build, not surprise-kill during Spike.
   - Use sound length, line wobble, timing, and color together so attentive players can learn the tells.

8. Set-pieces need rhythm placement.
   - Stage 3/5/7 beats should land in Build-late or Spike entry once validation is stable.
   - Same event in Calm feels like interruption; in Build/Spike it becomes drama.

## Design Rule
Do not add more fear just by raising numbers. A good rhythm phase should open or close a player decision. If a phase only changes pressure math, it is not finished yet.
